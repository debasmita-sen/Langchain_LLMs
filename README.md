# 🤖 LangChain AI Applications

A collection of AI-powered applications built using **Python**, **LangChain**, **OpenAI**, and **Groq APIs**. This project demonstrates how Large Language Models (LLMs) can be integrated into real-world applications such as chatbots, text summarization, resume enhancement, image generation, and automated content creation.

---

## 🚀 Features

- 💬 AI Chat Assistant
- 📝 Text Summarization
- 📄 Resume Skill Generator
- 💡 AI Comment Generator
- 🖼️ AI Image Generation
- ⚡ Groq LLM Integration
- 🔗 LangChain-based Workflows
- 🔐 Secure API Key Management

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/your-repository.git
```

Navigate to the project folder

```bash
cd your-repository
```

Install the required dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file and add your API key

```env
OPENAI_API_KEY=your_api_key
GROQ_API_KEY=your_api_key
```

---

## ▶️ Run the Project

Run any module individually.

Example:

```bash
python openai_chat.py
```

or

```bash
python groq_chat.py
```
